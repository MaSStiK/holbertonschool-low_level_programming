# holbertonschool-low_level_programming

A repository for learning low-level programming in C, including compilation, basic syntax, and standard library functions.

## Project Structure

```text
holbertonschool-low_level_programming/
├── benchmarking/
├── functions_nested_loops/
├── hello_world/
├── intro_debugging/
├── malloc_free/
├── more_functions_nested_loops/
├── more_malloc_free/
├── pointers_arrays_strings_1/
├── pointers_arrays_strings_2/
├── pointers_arrays_strings_3/
├── simple-calculator/
├── structures_typedef/
├── variables_if_else_while/
└── README.md
```

## Directories

- **`benchmarking/`** - Measuring C program execution time, comparing algorithm performance, profiling individual processing phases, and analyzing runtime efficiency.
- **`functions_nested_loops/`** - Function declarations and definitions, nested loops, character manipulation, arithmetic operations, and custom header files.
- **`hello_world/`** - Introduction to C programming, GCC compilation, preprocessing, basic input/output, and coding style.
- **`intro_debugging/`** - Debugging C programs using Python Tutor, tracing execution, inspecting variables, and fixing logic errors in loops and functions.
- **`malloc_free/`** - Dynamic memory allocation using malloc and free, string manipulation, two-dimensional arrays, memory management, and preventing memory leaks.
- **`more_functions_nested_loops/`** - Advanced functions and nested loops, character validation, arithmetic operations, number sequences, and printing geometric patterns.
- **`more_malloc_free/`** - Advanced dynamic memory allocation, string concatenation, zero-initialized arrays, memory reallocation, and error handling.
- **`pointers_arrays_strings_1/`** - Working with pointers, arrays, strings, memory addresses, string manipulation, and integer conversion.
- **`pointers_arrays_strings_2/`** - String concatenation, copying, comparison, character encoding, capitalization, and array manipulation.
- **`pointers_arrays_strings_3/`** - Memory manipulation, character and substring searching, multidimensional arrays, matrix diagonals, and double pointers.
- **`simple-calculator/`** - Building a terminal-based interactive calculator in C, including menu navigation, arithmetic operations, user input handling, and division-by-zero validation.
- **`structures_typedef/`** - Defining structures and custom types with typedef, initializing and printing structure members, dynamically allocating structures, and managing memory.
- **`variables_if_else_while/`** - Variables, conditional statements, relational and logical operators, and loops using if, else, while, and do-while.

Each directory contains C programming exercises for Holberton School tasks and its own `README.md` with descriptions of the files.
