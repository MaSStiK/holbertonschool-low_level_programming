# holbertonschool-low_level_programming

A repository for learning low-level programming in C, including compilation, basic syntax, and standard library functions.

## Project Structure

```text
holbertonschool-low_level_programming/
├── benchmarking/
├── functions_nested_loops/
├── hello_world/
├── intro_debugging/
├── more_functions_nested_loops/
├── pointers_arrays_strings/
├── variables_if_else_while/
└── README.md
```

## Directories

- **`benchmarking/`** - Measuring C program execution time, comparing algorithm performance, profiling individual processing phases, and analyzing runtime efficiency.
- **`functions_nested_loops/`** - Function declarations and definitions, nested loops, character manipulation, arithmetic operations, and custom header files.
- **`hello_world/`** - Introduction to C programming, GCC compilation, preprocessing, basic input/output, and coding style.
- **`intro_debugging/`** - Debugging C programs using Python Tutor, tracing execution, inspecting variables, and fixing logic errors in loops and functions.
- **`more_functions_nested_loops/`** - Advanced functions and nested loops, character validation, arithmetic operations, number sequences, and printing geometric patterns.
- **`pointers_arrays_strings/`** - Working with pointers, arrays, strings, memory addresses, string manipulation, and integer conversion.
- **`variables_if_else_while/`** - Variables, conditional statements, relational and logical operators, and loops using if, else, while, and do-while.

Each directory contains C programming exercises for Holberton School tasks and its own `README.md` with descriptions of the files.
