# holbertonschool-low_level_programming/argc_argv

## Files

- 0-whatsmyname.c - Print the program's name.
- 1-args.c - Print the number of command-line arguments.
- 2-args.c - Print all command-line arguments.
- 3-mul.c - Multiply two numbers passed as arguments.
- 4-add.c - Add positive numbers passed as arguments.
- 100-change.c - Calculate the minimum number of coins needed for change.
- _putchar.c - Write a single character to standard output using write.
- main.h - Declare function prototypes used throughout the project.
