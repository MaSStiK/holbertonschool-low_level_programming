# holbertonschool-low_level_programming/function_pointers

## Files

- 0-print_name.c - Print a name using a function pointer.
- 0-main.c - Test the print_name function.
- 1-array_iterator.c - Execute a function on each element of an array.
- 1-main.c - Test the array_iterator function.
- 2-int_index.c - Search for an integer using a comparison function.
- 2-main.c - Test the int_index function.
- 3-calc.h - Declare calculator functions and the operator structure.
- 3-get_op_func.c - Select a function based on the operator.
- 3-main.c - Perform arithmetic operations using command-line arguments.
- 3-op_functions.c - Implement addition, subtraction, multiplication, division, and modulo.
- _putchar.c - Write a single character to standard output using write.
- function_pointers.h - Declare function prototypes used throughout the project.
