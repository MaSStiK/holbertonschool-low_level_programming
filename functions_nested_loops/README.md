# holbertonschool-low_level_programming/functions_nested_loops

## Files

- 0-putchar.c - Print "_putchar" followed by a new line.
- 1-alphabet.c - Print the lowercase alphabet followed by a new line.
- 1-main.c - Test the print_alphabet function.
- 2-print_alphabet_x10.c - Print the lowercase alphabet 10 times, each on a new line.
- 2-main.c - Test the print_alphabet_x10 function.
- 3-islower.c - Check if a character is lowercase.
- 3-main.c - Test the _islower function.
- 4-isalpha.c - Check if a character is alphabetic.
- 4-main.c - Test the _isalpha function.
- 5-sign.c - Print the sign of an integer and return 1, 0, or -1.
- 5-main.c - Test the print_sign function.
- 6-abs.c - Return the absolute value of an integer.
- 6-main.c - Test the _abs function with positive, negative, and zero values.
- 7-print_last_digit.c - Print and return the last digit of an integer.
- 7-main.c - Test the print_last_digit function.
- 8-24_hours.c - Print every minute of the day from 00:00 to 23:59.
- 8-main.c - Test the jack_bauer function.
- 9-times_table.c - Print the 9 times table starting with 0.
- 9-main.c - Test the times_table function.
- 10-add.c - Add two integers and return the result.
- 10-main.c - Test the add function.
- 11-print_to_98.c - Print all integers from a given number to 98.
- 11-main.c - Test the print_to_98 function with different starting values.
- 101-natural.c - Calculate and print the sum of multiples of 3 or 5 below 1024.
- 102-fibonacci.c - Print the first 50 Fibonacci numbers.
- _putchar.c - Write a single character to standard output using write.
- main.h - Declare function prototypes used throughout the project.
