# holbertonschool-low_level_programming/hello_world

## Files

- 0-preprocessor - Run a C file through the preprocessor and save the output to a file named c.
- 1-compiler - Compile a C file into an object file without linking.
- 2-assembler - Generate assembly code from a C file.
- 3-name - Compile a C file and create an executable named cisfun.
- 4-puts.c - Print a string using puts.
- 5-printf.c - Print a string using printf.
- 6-size.c - Print the sizes of various C data types.
- 100-intel - Generate assembly code using Intel syntax.
- 101-quote.c - Print a string to standard error and return 1.
