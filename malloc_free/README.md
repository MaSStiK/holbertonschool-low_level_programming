# holbertonschool-low_level_programming/malloc_free

## Files

- 0-create_array.c - Create an array of characters using dynamic memory allocation.
- 0-main.c - Test the create_array function.
- 1-strdup.c - Duplicate a string using dynamically allocated memory.
- 1-main.c - Test the _strdup function.
- 2-str_concat.c - Concatenate two strings into newly allocated memory.
- 2-main.c - Test the str_concat function.
- 3-alloc_grid.c - Allocate and initialize a two-dimensional array of integers.
- 3-main.c - Test the alloc_grid function.
- 4-free_grid.c - Free a dynamically allocated two-dimensional array.
- 4-main.c - Test the free_grid function.
- _putchar.c - Write a single character to standard output using write.
- main.h - Declare function prototypes used throughout the project.
