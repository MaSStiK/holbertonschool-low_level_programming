# holbertonschool-low_level_programming/more_functions_nested_loops

## Files

- 0-isupper.c - Check if a character is uppercase.
- 0-main.c - Test the _isupper function.
- 1-isdigit.c - Check if a character is a digit from 0 to 9.
- 1-main.c - Test the _isdigit function.
- 2-mul.c - Multiply two integers and return the result.
- 2-main.c - Test the mul function.
- 3-print_numbers.c - Print digits from 0 to 9 followed by a new line.
- 3-main.c - Test the print_numbers function.
- 4-print_most_numbers.c - Print digits from 0 to 9, excluding 2 and 4.
- 4-main.c - Test the print_most_numbers function.
- 5-more_numbers.c - Print numbers from 0 to 14 ten times.
- 5-main.c - Test the more_numbers function.
- 6-print_line.c - Print a line of underscores of a given length.
- 6-main.c - Test the print_line function.
- 7-print_diagonal.c - Print a diagonal line using backslashes.
- 7-main.c - Test the print_diagonal function.
- 8-print_square.c - Print a square using hash characters.
- 8-main.c - Test the print_square function.
- 9-fizz_buzz.c - Print numbers from 1 to 100, replacing multiples of 3 and 5 with Fizz and Buzz.
- 10-print_triangle.c - Print a right-aligned triangle using hash characters.
- 10-main.c - Test the print_triangle function.
- _putchar.c - Write a single character to standard output using write.
- main.h - Declare function prototypes used throughout the project.
