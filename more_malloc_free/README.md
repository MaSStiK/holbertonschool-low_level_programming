# holbertonschool-low_level_programming/more_malloc_free

## Files

- 0-malloc_checked.c - Allocate memory and exit with status 98 on failure.
- 0-main.c - Test the malloc_checked function.
- 1-string_nconcat.c - Concatenate two strings using at most n bytes from the second string.
- 1-main.c - Test the string_nconcat function.
- 2-calloc.c - Allocate memory for an array and initialize it to zero.
- 2-main.c - Test the _calloc function.
- 3-array_range.c - Create an array of integers within a given range.
- 3-main.c - Test the array_range function.
- 100-realloc.c - Reallocate a memory block using malloc and free.
- 100-main.c - Test the _realloc function.
- _putchar.c - Write a single character to standard output using write.
- main.h - Declare function prototypes used throughout the project.
