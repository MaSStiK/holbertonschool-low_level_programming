# holbertonschool-low_level_programming/pointers_arrays_strings

## Files

- 0-strcat.c - Concatenate two strings.
- 0-main.c - Test the _strcat function.
- 1-strncat.c - Concatenate two strings using at most n characters.
- 1-main.c - Test the _strncat function.
- 2-strncpy.c - Copy a string using at most n characters.
- 2-main.c - Test the _strncpy function.
- 3-strcmp.c - Compare two strings.
- 3-main.c - Test the _strcmp function.
- 4-rev_array.c - Reverse an array of integers.
- 4-main.c - Test the reverse_array function.
- 5-string_toupper.c - Convert lowercase letters to uppercase.
- 5-main.c - Test the string_toupper function.
- 6-cap_string.c - Capitalize all words of a string.
- 6-main.c - Test the cap_string function.
- 7-leet.c - Encode a string into 1337.
- 7-main.c - Test the leet function.
- 100-rot13.c - Encode a string using ROT13.
- 100-main.c - Test the rot13 function.
- 101-print_number.c - Print an integer using _putchar.
- 101-main.c - Test the print_number function.
- _putchar.c - Write a single character to standard output using write.
- main.h - Declare function prototypes used throughout the project.
