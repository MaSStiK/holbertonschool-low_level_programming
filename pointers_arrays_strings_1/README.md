# holbertonschool-low_level_programming/pointers_arrays_strings_1

## Files

- 0-reset_to_98.c - Set the value of an integer to 98 using a pointer.
- 0-main.c - Test the reset_to_98 function.
- 1-swap.c - Swap the values of two integers.
- 1-main.c - Test the swap_int function.
- 2-strlen.c - Return the length of a string.
- 2-main.c - Test the _strlen function.
- 3-puts.c - Print a string followed by a new line.
- 3-main.c - Test the _puts function.
- 4-print_rev.c - Print a string in reverse.
- 4-main.c - Test the print_rev function.
- 5-rev_string.c - Reverse a string.
- 5-main.c - Test the rev_string function.
- 6-puts2.c - Print every other character of a string.
- 6-main.c - Test the puts2 function.
- 7-puts_half.c - Print the second half of a string.
- 7-main.c - Test the puts_half function.
- 8-print_array.c - Print elements of an integer array.
- 8-main.c - Test the print_array function.
- 9-strcpy.c - Copy a string to another buffer.
- 9-main.c - Test the _strcpy function.
- 100-atoi.c - Convert a string to an integer.
- 100-main.c - Test the _atoi function.
- _putchar.c - Write a single character to standard output using write.
- main.h - Declare function prototypes used throughout the project.
