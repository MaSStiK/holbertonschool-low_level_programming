# holbertonschool-low_level_programming/pointers_arrays_strings

## Files

- 0-memset.c - Fill memory with a constant byte.
- 0-main.c - Test the _memset function.
- 1-memcpy.c - Copy bytes from one memory area to another.
- 1-main.c - Test the _memcpy function.
- 2-strchr.c - Locate the first occurrence of a character in a string.
- 2-main.c - Test the _strchr function.
- 3-strspn.c - Calculate the length of a string prefix containing only accepted characters.
- 3-main.c - Test the _strspn function.
- 4-strpbrk.c - Find the first occurrence of any accepted character in a string.
- 4-main.c - Test the _strpbrk function.
- 5-strstr.c - Locate the first occurrence of a substring in a string.
- 5-main.c - Test the _strstr function.
- 7-print_chessboard.c - Print an 8x8 chessboard.
- 7-main.c - Test the print_chessboard function.
- 8-print_diagsums.c - Print the sums of the two diagonals of a square matrix.
- 8-main.c - Test the print_diagsums function.
- 100-set_string.c - Set the value of a character pointer using a double pointer.
- 100-main.c - Test the set_string function.
- _putchar.c - Write a single character to standard output using write.
- main.h - Declare function prototypes used throughout the project.
