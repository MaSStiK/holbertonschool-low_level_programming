# holbertonschool-low_level_programming/singly_linked_lists

## Files

- 0-print_list.c - Print all the elements of a singly linked list.
- 0-main.c - Test the print_list function.
- 1-list_len.c - Count the number of nodes in a singly linked list.
- 1-main.c - Test the list_len function.
- 2-add_node.c - Add a new node at the beginning of a singly linked list.
- 2-main.c - Test the add_node function.
- 3-add_node_end.c - Add a new node at the end of a singly linked list.
- 3-main.c - Test the add_node_end function.
- 4-free_list.c - Free all the nodes of a singly linked list.
- 4-main.c - Test the free_list function.
- 100-first.c - Print a message before the main function is executed.
- 100-main.c - Test the before_main function.
- _putchar.c - Write a single character to standard output using write.
- lists.h - Define the list_t structure and declare function prototypes used throughout the project.
