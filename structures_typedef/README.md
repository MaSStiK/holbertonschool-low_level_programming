# holbertonschool-low_level_programming/structures_typedef

## Files

- 0-main.c - Test the dog structure.
- 1-init_dog.c - Initialize a dog structure.
- 1-main.c - Test the init_dog function.
- 2-print_dog.c - Print information about a dog.
- 2-main.c - Test the print_dog function.
- 3-main.c - Test the dog_t type definition.
- 4-new_dog.c - Create a new dog with dynamically allocated strings.
- 4-main.c - Test the new_dog function.
- 5-free_dog.c - Free a dog structure and its allocated memory.
- 5-main.c - Test the free_dog function.
- dog.h - Define the dog structure, dog_t type, and function prototypes.
