# holbertonschool-low_level_programming/variables_if_else_while

## Files

- 0-positive_or_negative.c - Determine whether a random number is positive, negative, or zero
- 1-last_digit.c - Print the last digit of a random number
- 2-print_alphabet.c - Print the lowercase alphabet
- 3-print_alphabets.c - Print the lowercase and uppercase alphabets
- 4-print_alphabt.c - Print the lowercase alphabet without q and e
- 5-print_numbers.c - Print all single-digit decimal numbers
- 6-print_numberz.c - Print all single-digit decimal numbers using putchar
- 7-print_tebahpla.c - Print the lowercase alphabet in reverse order
- 8-print_base16.c - Print hexadecimal digits in lowercase
- 9-print_comb.c - Print all possible combinations of single-digit numbers
- 100-print_comb3.c - Print all unique combinations of two different digits
- 101-print_comb4.c - Print all unique combinations of three different digits
- 102-print_comb5.c - Print all unique combinations of two two-digit numbers in ascending order
