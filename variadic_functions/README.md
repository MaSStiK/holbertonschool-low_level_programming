# holbertonschool-low_level_programming/variadic_functions

## Files

- 0-sum_them_all.c - Return the sum of all integer arguments.
- 0-main.c - Test the sum_them_all function.
- 1-print_numbers.c - Print integers separated by a string.
- 1-main.c - Test the print_numbers function.
- 2-print_strings.c - Print strings separated by a string.
- 2-main.c - Test the print_strings function.
- 3-print_all.c - Print arguments of different types based on a format string.
- 3-main.c - Test the print_all function.
- _putchar.c - Write a single character to standard output using write.
- variadic_functions.h - Declare function prototypes and structures used throughout the project.
